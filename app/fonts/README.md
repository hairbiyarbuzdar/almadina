# Bundled fonts

These are the Latin variable WOFF2 font files previously downloaded by `next/font/google` for this site, retained from a successful local production build. They are loaded with `next/font/local` so builds do not require Google Fonts network access or its generated font-loader modules.

- `inter-latin-variable.woff2`: Inter, normal, weights 100–900.
- `cormorant-garamond-latin-variable.woff2`: Cormorant Garamond, normal, used at weights 400–700.

Both fonts use the SIL Open Font License 1.1. Their upstream licenses are included as `Inter-OFL.txt` and `CormorantGaramond-OFL.txt`; sources are the Google Fonts repository directories `ofl/inter` and `ofl/cormorantgaramond`.
